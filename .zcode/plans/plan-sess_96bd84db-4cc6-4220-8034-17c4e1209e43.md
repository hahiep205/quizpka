# Xoá hẳn `public/data` — đảm bảo production hoạt động bình thường

## Cơ sở an toàn (đã xác minh bằng phân tích code)
1. **Runtime không đọc `public/data`**: 10 môn free fetch từ R2 qua `toBankUrl()`; 27 môn paid fetch từ bucket Storage `paid-question-banks` qua edge function `get-paid-question-bank`. Không có `import`/`fetch` nào trỏ thẳng vào thư mục này.
2. **Bằng chứng Storage tự trọn**: 19/27 môn paid **không hề có** folder trong `public/data` (MAC102, LAW101, CIV101, SEC301…) mà paid quiz vẫn chạy bình thường — chứng tỏ Storage không phụ thuộc gì từ web host.
3. **Media an toàn**: trong 62 file còn lại, chỉ tadv-traphi tham chiếu media (prefix `tadv-traphi/` → đã ở R2); 5 folder bạn đã tự xoá trước đó (kiểm tra từ git HEAD) không tham chiếu media nào → không có hình/âm nào vỡ.
4. Đề-ảnh các môn GT101/PHY101… và `pdfUrl` không dùng `/data`.

## Thay đổi (5 mục)

### 1. Xoá thư mục
`git rm -r public/data` — 62 file, 8 folder (ky-nang-quan-ly-du-an, marketing-can-ban, nguyen-ly-tai-chinh, nhap-mon, phuong-phap-nghien-cuu, tadv-traphi, tin-hoc-van-phong, triet-hoc-mac-lenin). Sau bước này web host không còn serve bất kỳ file nào dưới `/data/*`.

### 2. `scripts/validate-data.js`
- Bỏ root `public/data` khỏi `bankRoots` (chỉ còn `r2-banks/data`), xoá const `publicDataDirectory`.
- `validateGeneralMedia`: thay check tồn tại trên disk bằng **bất biến mới** — media phải là absolute URL hoặc R2-hosted; nếu tham chiếu path local khác → fail với message rõ ràng (tránh âm thầm trỏ về `/data` đã chết).

### 3. Xoá pipeline sync cũ
- Xoá `scripts/sync-data.js` + bỏ script `sync:data` khỏi `package.json` (mục đích duy nhất của nó là đổ dữ liệu vào `public/data` — không còn ý nghĩa). Giữ `validate:data`.

### 4. Dọn test
`subjectBanks.test.ts` + `dashboardSweep.test.ts`: bỏ fallback `publicDataRoot` (bankFile chỉ resolve `r2-banks/data`), đổi tên test "exists under public/data" → "exists under r2-banks/data".

### 5. `README.md`
Cập nhật phần cấu trúc dữ liệu: free banks nằm ở `r2-banks/data/` (mirror R2 bucket `quizpka`, key prefix `data/`, serve qua `toBankUrl`), paid banks ở Supabase Storage (serve qua edge function), media qua `toMediaUrl` → R2; bỏ mô tả `public/data` và `sync:data`.

## Kiểm chứng trước khi giao

2. `npm test` — 260/260.
3. `ls dist/data` → **không tồn tại** (chứng minh web host sẽ không còn file nào).
4. Browser dev: quiz free (MAC101) + TOEIC full vẫn tải đề từ R2 bình thường.

## Triển khai & smoke test trên prod (bạn commit + push)
- Deploy xong, kiểm tra theo thứ tự: (a) 1 môn free (MAC101 Chương 3 — có ảnh) + TOEIC Full Test — JSON/audio từ `r2.dev`; (b) **2 môn paid có media**: tadv-traphi (audio Part 1) và marketing-can-ban — đề load từ edge function, Network tab **không có request `/data/*` nào**; (c) xuất PDF 1 môn free.
- `curl https://quizpka.online/data/tadv-traphi/test02/test02.json` → 404.
- Tuỳ chọn sau đó: bật Vercel Firewall block `/data/*` (path giờ trống hoàn toàn, chặn luôn mọi dòm ngó).

## Rủi ro / rollback
- **Rủi ro duy nhất**: nếu bản bank trên Storage của một môn paid nào tham chiếu media từng nằm ở `public/data` (khác bản local đã kiểm tra) → media vỡ sau deploy. Xác suất rất thấp vì bản local chính là nguồn upload và chỉ tadv-traphi có media (đã ở R2). Smoke test Network ở trên là lưới bắt; nếu thấy request `/data/*` nào bị 404, báo tôi để upload file đó lên R2 + thêm rewrite.
- Về nguyên tắc, việc xoá **không thể làm hỏng môn paid đang chạy được** — runtime chưa bao giờ đọc `public/data`.
- Rollback: `git revert` (toàn bộ 62 file nằm trọn trong git history).
- Không cần upload 8 folder paid lên R2 trước khi xoá — Storage mới là bản gốc của chúng.
